# Vision

**Second Credit** remakes simple 80s and 90s games as free, open-source software, with a modern, polished
presentation. The reference points are **Pac-Man Championship Edition** and **Tetris Effect**: keep the
original rules exactly as tight as they were, then put everything into lighting, materials, particles, sound,
music and feel.

## Principles

1. **Same rules.** Gameplay is recognisable to anyone who played the original. Timings, physics quirks and
   level layouts are respected. Modern additions (co-op, online, accessibility, quality-of-life options) are
   layered on top and can be turned off.
2. **Maps are sacred, graphics are ours.** If original or community maps exist, we are compatible with them
   ([level-packs.md](level-packs.md)). The visuals are entirely new.
3. **Free forever.** Open-source code and assets. No paid services in the pipeline ([stack.md](stack.md)).
4. **AI-built.** Claude Code does most of the programming, 3D modelling (via Blender), audio and level tooling.
   A human directs and tests. The project also shows what that workflow can do.
5. **Small, finished games.** Each game ships complete before the next one starts ([roadmap.md](roadmap.md)).
6. **One shared core.** Menus, input, audio, the level-pack loader, editors and capture tools are shared by
   every game.
