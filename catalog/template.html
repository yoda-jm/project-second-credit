Toolchain

zero budget · open licences

Godot 4 + Claude Code

MIT engine whose scenes and scripts are plain text, driven by Claude Code through the free godot-ai MCP. Headless captures under Xvfb let the agent see the running game.

Blender + MCP

Stylised, toy-like models that Claude builds with Blender Python, plus CC0 kits from Quaternius, Kenney, Poly Haven and ambientCG. Lighting, glow and particles in Godot do the heavy lifting.

Images, sound, music

ChatGPT image generation or local FLUX (Apache) for 2D. jsfxr and code-synthesised effects. Music composed as MIDI or tracker files and rendered with FluidSynth, or generated locally with ACE-Step (MIT).

Level packs

Free original levels ship in the repo. Data-only packs, open formats such as BDCFF for Boulder Dash, and importers that read the player's own original files keep classic layouts available without distributing them.

Screenshots come from Wikipedia and Wikimedia Commons (fair-use game captures, linked in each detail sheet) and are for private reference only. Game descriptions were drafted from memory and not verified; check level counts and exact numbers against the original game before building. Most of these names and characters are still owned trademarks, so a public release would need original naming and art.
