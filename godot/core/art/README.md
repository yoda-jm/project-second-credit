# Core art: provenance

`props/*.obj`: launcher props for games in development (traffic cone, gear), generated by
`tools/blender/launcher_props.py` (Blender 5.2, batch mode). CC BY-SA 4.0.

`shaders/gem.gdshader`: a copy of Glimmerdeep's gem shader for the launcher's floating gems (the launcher is
downloaded without the games). Our own, CC BY-SA 4.0.
