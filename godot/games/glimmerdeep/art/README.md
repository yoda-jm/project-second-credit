# Game 1 art: provenance

Original, CC BY-SA 4.0. All models are generated by `tools/blender/glimmerdeep_models.py` (Blender 5.2, batch mode;
run it to rebuild them). `tools/blender/preview_models.py` renders a contact sheet for review.
Shaders (`../shaders/`) and materials are written by hand in Godot; no textures are used.
